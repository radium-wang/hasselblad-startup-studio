# X2D II 静态开机图适配

`0.4.0-gen2-preview.1`，2026-10-27。本应用保持独立，不合入另一款相机扩展工具。macOS 和 Windows 源码均已适配；用户反馈 Mac 版实测正常，本次两端均开放预发布测试包；作者没有 Windows 电脑，因此 Windows 尚未实机测试。

## 支持范围

| 机型 | 固件 | 后端 |
| --- | --- | --- |
| 第一代 X2D 普通／大地、CFV 100C | 原厂 4.2.0 固定原库 | 既有独立模式 3；原厂身份及显示键保留 |
| X2D II 100C | 原厂 1.3.18.1，固定 GUI 和原图哈希 | 独立静态 Logo；不创建产品变体 |

其他二代固件、其他机型及未知第三方 Logo 修改均停止操作。不提供动画入口。

两端保留原有导入、基础裁剪、彩色／灰度及居中预览。图片最大 1024×768，不自动缩放；二代在黑色完整画布上按整数坐标居中，再编码为 BT.601 视频范围 NV12。原生 53 字节头部为 `width:1024 height:768 offset-x:0 offset-y:0 format:2;`，总长 1179701 字节。两端向共享引擎传递的 X2DLOGO3 只是电脑内部格式，不写进二代 Logo。

## 安装与恢复

二代使用 `/factory_data/logo.bin`。首次连接会在电脑保存经过完整读取校验的原图及内容、权限、UID/GID、mtime、安全标签基线。实际安装前，机内 `/factory_data/.hss-startup2` 保存原图、机身归属和先行写入的恢复记录；完成读回校验后才确认安装成功。

连续换图只更新自定义图记录，首次原图不变。原图和基线可从机内恢复到另一台电脑；Mac / Windows 使用同一记录格式，电脑备份与一代分目录保存。若机内原图损坏，必须有这台机身可验证的电脑首次备份才能恢复。未知图、跨机身记录、未知目录内容、缺失或损坏的两份备份均停止，不猜测原厂状态。

恢复使用原图字节及记录的属性，检查 SHA-256、大小、权限、UID/GID、mtime、SELinux 标签并清理本应用的机内安装文件。电脑首次备份继续保留。恢复范围是本应用的修改，不代表全机所有分区均与出厂镜像相同；inode、ctime、相机运行日志等不是可还原承诺。

## USB 与传输

二代为 VID/PID `2756:000B`、CTRL 接口 4，原组合 `rndis,mass_storage,bulk,acm`。两端先通过原生命令确认版本，再核对平台、GUI 哈希和文件基线；同一时刻只接受一台相机。Windows 只打开匹配的 `MI_04` WinUSB 接口，不能替换整个复合设备的驱动。

小文件走有界诊断通道，超过 8192 字节的压缩上传走临时 ADB。先在私有 RAM 挂载中安排设备端自动撤回脚本，再临时追加 ADB 接口 6。App 使用自有端口和服务进程，不关闭用户全局 ADB，不改 `persist.*`、认证设置或 SELinux。操作结束核对原 USB 状态、adbd 停止、属性及私有文件清理；不确定的写入不自动重发。无法确认收尾时明确报错，要求完整关机再开机后检测。

Windows 大文件另需正确的 `MI_06` ADB 驱动。本程序不自动安装驱动。驱动适配尚无真实 Windows 二代相机验收。

## 验证边界

此前单台二代底层试验已确认：彩条、文字及边框正常，完整关机再开机显示正确；撤回后原厂 H 和正常拍摄界面恢复。内容和记录属性、USB 原状态、试验目录清理均核对通过。该证据不等于本次完整 App 已上机验收。

共享引擎 28 个离线测试执行实际生成的安装／恢复脚本，覆盖连续换图、首次备份不可覆盖、另一台电脑恢复、机内损坏时使用电脑备份、未知图与外来文件拒绝，以及 31 个持久语句中断恢复点。另测颜色向量、灰度及奇数尺寸、原生版本与完整 1024 字节填充块、分片及超时带数据、Windows 接口选择、UTF-8 进程协议、临时通道收尾和默认不访问设备。

文件内容、权限、mtime 使用私有本地文件系统；UID 与 SELinux、USB 及服务为替身。中断注入不是断电耐久测试。Mac 两种架构各 75 项、C/Swift USB 替身 31 项、另 5 项 Mac 二代进程协议、Windows 核心与 headless UI 253 项（含 7 项二代进程协议和 2 项二代匿名诊断）已通过。最终 Mac 包内引擎也在 arm64 和 x86_64 下通过实际导入、编码与无设备入口检查。Rosetta 与跨平台控件检查不等于真实 Intel 老系统或 Windows 电脑验收。

2026-10-27，用户反馈“mac 我测试了没问题”，授权上传 Mac 版。本次据此记录为单台 Mac / 二代机器的实测正常反馈；该反馈未逐项列出每一步结果，不扩展为其他机型、其他固件或全部中断路径的验收。

Windows 的 MI_04 / MI_06 驱动及检测→安装→冷启动→再次换图→恢复→冷启动完整流程仍待真实电脑与相机验收。本次两端均提供预发布测试包；Windows 下载已明确标注作者没有 Windows 电脑、尚未实机测试，不将离线／云端检查表述为真实相机验收。
